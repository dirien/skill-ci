# Adopters

This page lists organizations and projects that use skill-ci. If you use it, please add yourself. It helps the project show that skill-ci is used outside its maintainers' own work, and it helps other users find people with the same setup.

## How to add yourself

1. Fork the repository and add a row to the table below. Keep the table sorted by name.
2. Open a pull request with the title `docs: add <organization> to ADOPTERS.md`. Sign off the commit (`git commit -s`), as [CONTRIBUTING.md](CONTRIBUTING.md) describes.

The person who opens the pull request should be allowed to speak for the organization about its use of skill-ci.

| Column | What to write |
| --- | --- |
| Organization | The name, linked to its website |
| Contact | A GitHub handle the maintainers can ask about the entry |
| Since | The month you started, for example `2026-11` |
| How you use skill-ci | One or two sentences: what kind of skills you evaluate, with which agents, and in which environment (testing or production) |
