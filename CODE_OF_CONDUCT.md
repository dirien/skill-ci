# Code of Conduct

skill-ci follows the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md). It applies to everyone who takes part in the project: in issues, pull requests, reviews, chats and at events where you represent the project.

## Reporting

If you see or experience behavior that breaks the Code of Conduct, contact the maintainer, Engin Diri, privately through the contact options on his GitHub profile, [github.com/dirien](https://github.com/dirien). Do not report it in a public issue.

The project does not have its own reporting address yet. This section will name one when it exists.

Reports are kept confidential. The maintainer will acknowledge your report, look into it and tell you what was decided. If your report is about the maintainer, you can also report the content to GitHub ([reporting abuse or spam](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)).

GitHub private vulnerability reporting is for security issues only. To report a vulnerability, follow [SECURITY.md](SECURITY.md).
