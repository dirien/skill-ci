# AGENTS.md

skill-ci is CI for agent skills on Kubernetes. A skill pushed to Harbor as an OCI artifact triggers a `SkillEval`; the controller runs the runner Job, which evaluates the skill with NVIDIA SkillEvaluator in Agent Sandbox pods, and the gate moves or withholds the skill's tags. [README.md](README.md) is the overview, [docs/architecture.md](docs/architecture.md) the walkthrough.

## Commands

`make help` lists all targets. CI (`.github/workflows/ci.yaml`, `lint.yaml`, `chart.yaml`) runs the same commands; a change must pass all of them.

| Task | Command |
| --- | --- |
| Go vet, test, build | `cd controller && go vet ./... && go test -race ./... && go build ./...` |
| Go lint | `cd controller && golangci-lint run ./...` (CI pins v2.15.0) |
| Regenerate DeepCopy and CRDs after an API change | `make -C controller generate manifests && make chart-crds` |
| Python tests | `uv run --no-project --with-requirements .github/requirements-ci.txt --with ./harbor-agent-sandbox python -m pytest` |

## Rules that bind

- A change to a shared interface (CRD field, Job env, statistics, tag policy, metrics, API route) updates [CONTRACT.md](CONTRACT.md) in the same commit.
- `ui/src/api/types.ts` mirrors `controller/internal/reportsite/apiv1` by hand; the Go types are the source. Change both, then regenerate the fixtures: `TestFixturesMatchTypes` decodes each one into its Go type.
- Versions shared by the two install paths live in `deploy/versions.env` and `infra/Pulumi.yaml`; `deploy/check-versions.sh` fails on a mismatch. A release bumps both, plus `charts/skill-ci-controller/Chart.yaml`, `config/`, `runner/job.yaml`, the docs and [CHANGELOG.md](CHANGELOG.md); `git show --stat` of the last `chore: point the chart, ...` commit lists every file ([docs/releasing.md](docs/releasing.md)).
- UI dependencies are pinned exactly, and each version was published at least 14 days before it was chosen. Dependabot's npm cooldown is 14 days; [ui/README.md](ui/README.md) shows how to resolve the lockfile with `--before`.
- A SkillEvaluator change goes into `skillevaluator-patch/skillevaluator-0.6.0-skill-ci.patch` as a new hunk, and `runner/check_patch.py` gets a check that fails when the hunk no longer takes effect.
- Agent output and trial content are untrusted. The UI renders them as text only, under a strict CSP with no inline scripts or styles ([ui/README.md](ui/README.md#rules)); trial bundles are redacted fail-closed before upload.
- Never print, log or commit API keys. LLM keys reach the cluster as the `llm-keys` Secret ([docs/agents-and-models.md](docs/agents-and-models.md)).
- `make down` refuses on purpose: `pulumi destroy` deletes the cluster, Harbor and every skill. Only a person runs it.

## Conventions

- Go: every exported symbol has a doc comment starting with its name; wrap errors with `fmt.Errorf("...: %w", err)`; table-driven tests next to the code.
- Python: ruff settings in `ruff.toml`; tests stub ORAS and SkillEvaluator, so no runner image is needed.
- Commits: [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) `type(scope): summary`, lower case, no final period. Scopes in use: `controller`, `runner`, `sandbox`, `chart`, `deploy`, `infra`, `demo`, `dashboard`, `deps`, `ui`. One logical change per commit.
- Sign off every commit (`git commit -s`); the DCO workflow checks pull requests ([CONTRIBUTING.md](CONTRIBUTING.md#developer-certificate-of-origin)).
- Markdown: linted by markdownlint (`.markdownlint.yaml`); prose lines are not wrapped; no em or en dashes in docs or UI text.
- Behavior change: tests and docs in the same pull request. Docs map: [CONTRIBUTING.md](CONTRIBUTING.md#documentation).

## Trying a change on a cluster

[deploy/README.md](deploy/README.md) installs a release on any Kubernetes cluster (`deploy/install.sh`). On the Pulumi stack, `make up` creates the cluster and `make deploy` installs the release in `skillCiVersion`. `make check-skills` checks the sample skills without LLM calls; `make reports-ui` and `make dashboard` port-forward the reporting site and Grafana.
