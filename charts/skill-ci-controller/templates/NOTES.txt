Platform settings (network modes, default SandboxProfile) live in the SkillCIConfig "default" and
sandbox sizes in SandboxProfiles, both in namespace {{ include "skill-ci-controller.watchNamespace" . }}. The chart
creates them only when they do not exist yet; after that they are yours to edit, and upgrades never
overwrite them:
  kubectl -n {{ include "skill-ci-controller.watchNamespace" . }} get scc default
  kubectl -n {{ include "skill-ci-controller.watchNamespace" . }} edit scc default
  kubectl -n {{ include "skill-ci-controller.watchNamespace" . }} get sbp

Helm installs crds/ only on the first install and never upgrades them. When upgrading from an older
chart, apply them first (0.10.0 adds the SkillCIConfig CRD, 0.9.0 the SandboxProfile CRD, 0.5.0 SkillEval
status fields): kubectl apply --server-side -f charts/skill-ci-controller/crds/

Try it:

  kubectl -n {{ include "skill-ci-controller.watchNamespace" . }} get skillevals
